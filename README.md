# Taniti Travel Website

Taniti is a responsive travel and tourism website designed to showcase a fictional island destination. The project focuses on clean UI, user-friendly navigation, and presenting information in a visually engaging way.

## Overview
Taniti was built as a front-end focused project to simulate a real-world travel website experience. The goal was to create a clean, responsive interface that allows users to easily explore destinations, activities, and essential travel information.

## Features
- Responsive design for desktop and mobile
- Clean and modern UI layout
- Navigation for exploring island activities and locations
- Structured content for tourism-based information
- User-friendly interface focused on readability

## Tech Stack
- HTML
- CSS / SASS
- JavaScript
